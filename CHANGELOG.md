# Changelog

Every merge to `main` sends an "update available" notice to everyone who deployed this template. Breaking changes are listed first in each entry.

## 2.1.1-railway.1 (2026-11-24)

First release of the template.

- Transmute `v2.1.1`, official image `ghcr.io/transmute-app/transmute:2.1.1@sha256:87b669d835d9e68bdbc4082ab061cb361cd3ecee69c14ccfa9a3814d326b6707`.
- First admin created on first boot from `TRANSMUTE_ADMIN_USERNAME` / `TRANSMUTE_ADMIN_PASSWORD` (upstream lets the first visitor become admin).
- `AUTH_SECRET_KEY` kept stable across restarts (generated by the template, with a fallback saved on the volume).
- Worker counts, ffmpeg threads and OCR/BLAS thread pools sized from the container's CPU and memory limits.
- Start script exits non-zero if Transmute stops unexpectedly, so Railway restarts it.
